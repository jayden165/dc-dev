# Mr Savage – Discord Developer Portfolio

A static one-page portfolio (HTML/CSS/JS). No build step, no server code, no environment variables.

## Files
- `index.html` – the whole site (about, skills, work, payment, request template, FAQ, contact)
- `style.css` – styles
- `script.js` – nav, filters, mock bot demo, copy buttons

## Deploy
Push to GitHub, then either:
- **Vercel:** import the repo, Framework Preset "Other", no build command; or
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.

## Editing the request template
The text people copy lives in the `<pre id="template">` block in `index.html`.
